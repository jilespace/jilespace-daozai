# 产品路线图：对标 Notchy 与岛仔的迭代方向

> 最近更新：2026-11-10。本文是「先看懂、再对标、后迭代」的工作底稿：
> 上半部分记录岛仔现状，中段是 [Notchy](https://notchy.dev/zh-hans/) 的公开功能清单与差距，
> 末段是本项目后续的迭代顺序与 UI 原则。功能取舍以「顶部信息岛」这个形态为先，
> 不追求把 Notchy 的 131 个功能全部平移到 Windows。

## 一、岛仔现状（v0.6.49 + 未发布改动）

技术栈：Rust 2021 + egui/eframe 0.31（Glow 后端），Windows 原生窗口（无边框、透明、
置顶、点击穿透）、Win32/WinRT 直连系统能力，无 Electron / 无 WebView。

| 模块 | 当前能力 | 关键实现 |
| --- | --- | --- |
| 岛体 | 悬停意图缓冲、弹簧展开/收起、翻页、极简刘海、全屏隐藏、多显示器定位、点击穿透 | `app.rs`、`shape.rs`、`glass.rs`、`native.rs` |
| 桌面伙伴 | 会眨眼/打盹/喝水/唱歌的小吉祥物，极简模式可关 | `pet.rs` |

| 专注与饮水 | 番茄钟、休息计时、饮水目标/快捷记录/撤销、提醒时段 | `pages.rs`、`model.rs` |

固定底栏与滚动条、可复现的离屏渲染截图。

**已知边界**：Gmail 需可访问 Google；钉钉/企业微信日历尚未完成真实账号验收；
歌词与额度接口受服务商策略影响；未做商业代码签名；无 macOS/Linux 包。

## 二、Notchy 公开功能盘点（对标基准）

Notchy（macOS 13+，闭源，一次性 $24.99，v2.0.6）把 macOS 刘海变成灵动岛，
公开宣传「50 多项功能 / 131 篇功能指南」，官方站点按八组呈现。以下为与 Windows
顶部信息岛相关的部分（省略明显依赖 Apple 生态的能力）：

### 1. 灵动岛本体
- 刘海自定义：形状、尺寸、圆角、行为；无刘海设备上的悬浮岛；多显示器。
- Live Activities（计时器、下载、通话的实时活动）、计时/世界时钟、股票行情。
- Liquid Glass 材质；134 种语言本地化；Siri 运行时的联动岛。

### 2. 音乐与音频
- 正在播放（封面、拖进度、控制）、LRCLIB 同步歌词、听歌识曲。
- 系统音频 FFT 可视化、输出设备切换、单应用音量/EQ/输出路由。
- AirPods 连接与电量、音量 HUD、麦克风静音、播客 ±15s、倍速播放。

### 3. 专注与时间
- 番茄钟、专注音效、打字音效、倒计时/秒表、macOS 专注模式联动。
- 活动环、屏幕使用时间、20-20-20 休息提醒、防睡眠。
- 日历（Google/Outlook/CalDAV/.ics）、全屏会议提醒、提醒事项、待办、快速笔记、世界时钟。

### 4. 文件与剪贴板
- 剪贴板历史、纯文本粘贴、复制时清理跟踪参数。
- OCR 取字（截图/图片转文本）、文件拖放暂存架、AirDrop、截图暂存、滚动截图、截图标注。
- 本地 AI 剪贴板（润色/改写）、图片转换/压缩、压缩包、PDF 合并、视频转 GIF。
- 下载进度、推出磁盘、录屏、扫码。

### 5. 系统与硬件
- 系统监视器（CPU/GPU/内存/网络）、流量统计、CPU 温度、GPU 监视、磁盘空间。
- 电池健康/电量提醒/充电上限、设备电量（键鼠/触控板/iPhone）、外接显示器亮度/色温。
- 刷新率切换、键盘背光、大写锁定指示、键盘清洁、天气、Wi-Fi 信号/密码、USB 设备。
- 应用更新器、应用卸载器、桌面宠物（23 种像素宠物）。

### 6. 输入、快捷键与窗口
- 全局快捷键、应用启动器、启动轮盘、命令面板（⌘K）、快捷搜索与翻译、单位换算、表情选择。
- 窗口吸附（半屏/四分之一/三等分）、空间切换、文本片段、离线听写、快捷指令。
- 按键可视化、光标高亮、划词操作、取色器、HomeKit 控制。

### 7. 通知与隐私
- 通知镜像到刘海、通知横幅位置、来电/消息回复、会议通话指示。
- 摄像头/麦克风占用提醒、摄像头镜像、提词器。
- 隐藏菜单栏图标、锁屏小组件/歌词、桌面小组件、人脸解锁、自定义提醒音。

### 8. 开发者与 AI
- AI 用量追踪（Claude/Codex/Cursor 等的限额与花费）、限额重置时间。
- Claude Code 通知与权限确认、终端岛（VT100）、长命令完成提醒、Homebrew GUI、端口占用排查。

## 四、迭代顺序（UI 优先）

原则：每一轮都必须有可验证的界面产出（离屏 PNG 或真机截图）、有测试兜底、
有更新记录；功能先做「顶部信息岛」自然承载的，再考虑独立面板。

1. **Phase A（进行中）剪贴板快捷面板收口**：完成重设计、截图验收、回归测试、
   文档与更新记录；补齐低风险增强（纯文本粘贴、清理链接候选）。
2. **Phase B（已完成基础版）命令面板**：`Ctrl+Alt+K` / 托盘入口；键盘优先；分组检索
   功能页、设置项、本机应用；内置单位换算与计算；统一面板视觉令牌（`src/panel.rs`）。
   后续增强：剪贴板结果、快捷搜索/翻译、自定义常用项。
3. **Phase C（已完成基础版）系统页**：CPU/内存/网络/磁盘实时采样 + 48 秒迷你折线；
   每秒刷新、缓动展示、悬停详情；设置页支持显隐与排序。后续补 GPU/温度与进程排行。
4. **Phase D（已完成）OCR 取字**：剪贴板图片与屏幕框选两种取字，经 Windows.Media.Ocr
   本地识别，结果自动复制并写入历史；全屏遮罩支持压暗、刻度、尺寸标签与 Esc 取消。
   后续可补多语言引擎选择与识别结果预览。
5. **Phase E（已完成）小工具集**：防睡眠、世界时钟、倒计时/秒表；计时页与收起态药丸联动。
   后续可补快速笔记与「计时结束打开指定动作」。
6. **Phase F（已完成基础版）外观自定义**：不透明度/圆角/动效强度与设置页实时预览；
   多显示器与 DPI 细节审计仍待继续。
7. **Phase G（基线已建立）性能与稳定性**：启动/空闲 CPU/内存基线、刷新策略回归护栏、
   解析与配置容错测试已落地（见 `docs/PERFORMANCE.md`）；后续继续压内存、冷启动与
   24 小时长时运行回归。
8. **Phase H（已完成基础版）天气页**：Open-Meteo 当前天气 + 6 小时预报、矢量天气图标、
   本机缓存与离线回退；后续补多日预报、定位与生活指数。
9. **Phase I（已完成基础版）通知历史**：系统通知镜像、`Ctrl+Alt+N` 面板、未读计数、
   本机持久化与复制/删除/清空；后续补按应用过滤、免打扰时段与通知快捷回复。

## 五、UI 规范草案（新面板统一遵守）

- **颜色**：石墨底 `#1E1F22`，浮层 `#27282C`，悬停 `#2F3035`，描边 `#404146`，
  正文 `#F6F7F9`，次级 `#A6A8AF`，强调蓝 `#3EACF8`，警示黄 `#FFC43D`，危险红 `#FF7070`；
  浅色主题对应 `#FBFCFD / #F4F6F9 / #ECEFF4 / #DEE2E8 / #1E2229`。
- **网格**：4pt 基础网格；面板内边距 18；行高 54；圆角 18（面板）/12（卡片）/9（行）/6（标签）。
- **字体**：Segoe UI + 微软雅黑 UI 三档字重；标题 16 Semibold，正文 13，说明 11.5，
  元信息 10.5，键帽 9.5。
- **动效**：进入 130ms 淡入 + 轻微上移；悬停 90–110ms；页签下划线 160ms；
  展开/收起少用线性，优先弹簧与 `ease_out_cubic`；尊重系统「减少动画」。
- **状态**：每个面板必须覆盖「未开启 / 空 / 无结果 / 加载中 / 失败 / 成功回执 / 可撤销」；
  错误留在面板内，不丢到岛体上。
- **可达性**：全部操作有键盘路径；焦点可见；对比度 ≥ 4.5:1（正文）；点击目标 ≥ 24pt。

## 六、验收方式

- `cargo test --locked --all-targets --features record -- --test-threads=1` 全量通过。
- 无窗口渲染：`DAOZAI_CLIPBOARD_PREVIEW_DIR=... cargo test --lib clipboard_ui`
  输出面板 PNG，人工检查间距、对齐、主题与极端状态。
- 录制器 `daozai-record --gallery <dir>` 生成岛体各页截图，作为回归基线。
- 真机操作作为最终验收：托盘、热键、粘贴回原应用、多显示器、DPI 125%/150%。
