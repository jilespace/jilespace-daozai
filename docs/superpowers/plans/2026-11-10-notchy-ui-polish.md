# Notchy 参照下的 UI 与交互统一

目标：在现有 Rust/egui 界面上落实一轮整体一致性打磨，覆盖剪贴板、命令面板、通知和设置。
用户已选择整体一致性，并指定对标 Notchy。沿用深浅主题和现有 Windows 快捷键。

## 参考与边界

- 参考 https://notchy.dev/ 的可交互剪贴板与设置演示，以及 https://notchy.dev/help/settings/。
- 借鉴内容优先的紧凑层级、搜索与快捷操作、次要操作收纳和即时反馈。
- 保留现有功能与数据模型，不引入 macOS 权限、玻璃模糊或新的外部服务。
- 保留本聊天上一轮未提交的 WGL 透明修复。

## 验收

- 搜索输入保留数字、中文和空格；清除后焦点留在输入框。
- Esc 不跳过确认框/预览，也不与同帧 Enter 一起执行操作；空查询时关闭浮窗。
- 设置 Esc 仅在搜索有内容且无弹出菜单时清除搜索，不丢弃其他表单编辑。
- 通知卡片标题、正文、操作不互相挤压；删除/静音仍可通过菜单执行。
- 新增自绘控件支持键盘焦点可见；减少动画时直接到最终态。
- 空闲控件不再持续请求下一帧。
- 验证命令：`cargo test --locked --all-targets --features record -- --test-threads=1`；
  `cargo run --locked --example viewport_transparency`；`cargo build --locked --release --bin daozai`。

截图输出：`preview/ui-polish-before/` 和 `preview/ui-polish-after/`（忽略目录，仅合成数据）。
