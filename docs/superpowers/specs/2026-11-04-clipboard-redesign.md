# 剪贴板快捷粘贴面板重设计

用户已选择本轮生成的第一张视觉稿：深灰浮层、搜索、置顶与最近复制分组、轻蓝选中状态和固定底栏。

## 目标与范围

面板优先服务「呼出、查找、粘贴回原应用」。继续使用 Rust/egui 和现有 DPAPI 文本历史，不新增网页或云服务。

面板自然尺寸约 560 × 520 逻辑点；跟随系统深浅主题。保留 14–16 点正文、清楚的时间层级、轻分隔线与外层阴影。优先在光标附近出现并限制在工作区内。首次定位后不随鼠标移动。

## 交互契约

- Ctrl+Alt+V 呼出时记住外部前台窗口并聚焦搜索；托盘入口无法取得外部目标时提供仅复制。
- 搜索即时过滤，选择保留条目身份；后台新记录不得改变当前选中条目。
- 单击选择，双击或 Enter 粘贴；Ctrl+Enter 仅复制。
- 方向键选择并滚动到可见区域。空格在搜索输入中正常输入；预览由明确按钮触发，非文本编辑时才允许空格快捷预览。
- 多行预览保留换行，命令和路径采用等宽字体；预览可关闭。
- Delete 在搜索中只编辑文字，删除历史由条目菜单触发；删除提供短时撤销。
- 置顶、预览、删除等次级操作进入菜单。暂停、未启用、无记录、搜索无结果、热键冲突、写入失败都有明确状态。
- 粘贴流程必须先确认系统剪贴板写入成功，再关闭浮层、恢复目标窗口、检查前台并发送粘贴。失败后不向其他窗口发送输入，明确提供手动粘贴提示。不声称目标应用已接受文本。
- Esc 返回原应用；点击外部关闭时不抢回焦点。

## 验证

补充身份稳定、编辑键不误删、复制与粘贴命令、失败保留面板、撤销、布局和长文本等回归。使用合成文本和独立数据目录验证，禁止读写真实账号或私人剪贴板历史。运行相关测试和项目全量测试，再构建；实机操作或截图受阻时如实报告，不以编译代替视觉验收。
