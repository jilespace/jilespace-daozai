# 使用指南

## 第一次打开

鼠标靠近屏幕顶部的小岛会展开功能面板。左右箭头和底部圆点切换页面；在列表内部滚轮查看更多内容。托盘菜单可打开设置、控制开机启动或退出程序。

设置里的功能显示开关可以隐藏不常用的页面；隐藏页面不等于删除它的数据。

## 邮箱

在「设置 → 邮件」添加完整邮箱地址，选择服务商并填写授权码或 App 专用密码。不要把密码发送到聊天、Issue 或截图里。

| 邮箱 | 获取连接凭据 |
| --- | --- |
| QQ | QQ 邮箱网页版右上角「设置」→「账号与安全」→「安全设置」→「POP3/IMAP/SMTP/Exchange/CardDAV 服务」→开启服务并生成授权码 |
| 163／126 | 邮箱网页版「设置」→「POP3/SMTP/IMAP」→开启 IMAP，并按页面验证生成客户端授权密码 |
| 腾讯企业邮 | 网页版设置中的客户端收发设置；企业管理员可能限制 IMAP 或第三方客户端 |
| iCloud | Apple 账号开启双重认证后，在账号安全页面生成 App 专用密码 |
| Gmail | Google 账号开启两步验证后生成应用专用密码；单位账号可能由管理员禁用此入口 |

以服务商当前页面为准，岛仔设置页也提供对应说明和网页入口。Gmail 在部分网络环境下需要能够访问 Google；岛仔不会替你改变系统网络设置。

连接后读取最近 20 封邮件；运行期间列表最多保留 60 封。新邮件优先通过 IMAP IDLE 接收，并有定期防漏检查；服务器、网络及服务商投递耗时仍会影响实际到达时间。

验证码卡片显示来源与主题，点击即可复制。点邮件列表进入详情，滚轮查看正文；「阅读全文」打开独立阅读窗口。正文内的网页链接交给默认浏览器打开。

## 日程

在「设置 → 日程」选择平台，填写平台提供的 CalDAV 连接信息。只登录或安装飞书、钉钉、企业微信桌面客户端，不会自动授予岛仔日历读取权限。

- 左侧月历选择日期；右侧按时间显示日程，全天安排在前。
- 大卡片显示选中的日程；滚轮只滚动下方列表，点击其他条目切换大卡片。
- 跨天日程会出现在覆盖的日期中。结束时刻按日历提供的数据展示。
- 自动同步默认每 5 分钟进行；点击右上角更新时间可手动刷新月份。
- 提前提醒时间可在设置中选择 5／15／30 分钟；全天安排展示在日历中，不在午夜弹出会议提醒。
- 普通邮件正文中的日期不会加入日程；带日历附件的正式邀请会自动显示。
- 邮件日程右侧的 × 可忽略该日程，停止显示与提醒；在邮件详情或全文窗口选择「恢复日程」可恢复。忽略邮件来源不会删除工作日历中的对应安排。

**当前边界：** 邮件日程依赖当前加载的邮件记录，不是完整邮箱归档；复杂的批量重复规则修改可能提示不支持。日历同步失败会显示错误，不能把“已连接”当成所有日程都已成功同步。程序退出、电脑关机或睡眠期间无法持续接收提醒。

## 音乐、专注、饮水与待办

音乐来自 Windows 媒体会话，播放器需要提供系统媒体信息。歌词匹配依赖歌曲元数据和外部服务，个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

专注与休息需点击开始，结束后可进入下一阶段。饮水可设置目标、单次量、提醒间隔和时段；记录错误可以撤销。待办提醒是可选项，填写任务后通过日期／时间选择器设置，不需要手写时间格式。

## AI 额度

先登录相应工具，再在岛仔 AI 额度设置中识别本机账号。多个账号可分别命名、选择配色并决定是否常驻。Codex、Claude、Kimi 的本机登录由原工具管理，岛仔不会修改它们的配置。

Grok Bot、Gemini 提供各自的连接入口；会话过期时重新连接。额度接口、订阅类型和服务商策略可能变化，未识别或请求失败时应以对应服务的官方页面为准。

## 剪贴板历史

按 `Ctrl+Alt+V` 打开剪贴板快捷面板，面板会记住唤起前的应用并自动聚焦搜索框。
输入关键词即时过滤，命中的文字会高亮；如果命中位置在后面的行，条目会显示那一行。
`↑/↓` 选择并滚动到可见位置，`Enter` 把内容写回原应用，`Ctrl+Enter` 只复制，
`Esc` 关闭面板（预览中先退回列表）。点击条目只选择，双击直接粘贴。

- 「最近／置顶」页签切换筛选；条目右键菜单提供粘贴、仅复制、预览、置顶和删除。
- 预览会替换列表并显示完整多行内容，可用鼠标选择文字；删除后 6 秒内可在底栏撤销。
- 右上角菜单可以暂停／恢复记录、清空全部（需要再次确认）、打开设置或关闭面板。
- 面板跟随系统深浅色。若目标窗口无法恢复或剪贴板正被占用，面板会保留并显示原因，
  不会把“已复制”当作“已粘贴”，也不会向其他窗口误发按键。

历史默认关闭，首次使用时在弹窗内开启；置顶项不会被自动清理。内容使用 Windows DPAPI
加密保存在本机。搜索框中的 `Delete` 只编辑搜索文字，不会删除历史条目。

## 命令面板

按 `Ctrl+Alt+K`（或托盘菜单「命令面板」）打开。输入关键词即可搜索：

- **操作**：打开剪贴板历史、开始/暂停专注、打开日程、暂停剪贴板记录、打开设置。
- **页面与设置**：直接跳到任意可见功能页，或跳到某个设置标签。
- **应用**：开始菜单里的程序（含 `.lnk`／`.url` 快捷方式），按名称模糊匹配。
- **计算**：直接输入 `12*8`、`(1+2)*3`、`2^10`，第一行显示结果，`Enter` 复制。
- **单位换算**：`90f to c`、`1 gb to mb`、`10 公里 to 英里`，支持长度、重量、
  数据、速度、时间与温度，`Enter` 复制带单位的结果。
- **世界时钟**：输入「东京」「伦敦」「new york」等城市名，直接显示当地时间，`Enter` 复制。

`↑/↓` 选择，`Enter` 执行，`Esc` 关闭；面板跟随系统深浅色。全局热键被其他程序
占用时，可从托盘菜单打开命令面板，剪贴板热键状态显示在「设置 → 剪贴板」。

## 图片文字识别

两种取字方式都使用 Windows 本地 OCR，图片不会上传：

- **剪贴板图片**：复制截图或图片后按 `Ctrl+Alt+O`。
- **框选屏幕**：按 `Ctrl+Alt+Shift+O`，在光标所在屏幕拖动框选任意区域，松开后识别。
  选区外压暗、四角有白色刻度，左上角显示像素尺寸；`Esc` 取消。

也可以从托盘菜单「识别图片文字 / 截屏取字」、剪贴板面板右上角菜单或命令面板
（搜索「识别 / OCR / 截屏 / 框选」）触发。识别结果会自动复制到剪贴板，并作为一条
记录加入剪贴板历史；识别期间岛体会保持动画，完成或失败都会给一条岛上提示。

- 支持剪贴板里的 DIB/DIBV5 图片（1/4/8/24/32 位、自顶向下或自底向上）与 PNG 格式，
  常见截图工具复制的图片都能直接识别。
- 剪贴板只有文本或没有图片时会提示；OCR 语言包不可用时会在系统设置中提示安装。
- 识别在后台进行，不会卡住岛体动画。

## 岛体外观

「设置 → 岛体外观」可以调整岛体本身的不透明度、圆角与动效，改动立即生效：

- **不透明度**：45%–100%。调低后桌面会透出来，文字与图标保持不透明以保证可读。
- **圆角**：60%–160%，只影响岛体下沿与通知条。
- **动效**：跟随系统（读取 Windows「显示动画」设置）、完整或关闭；
  关闭后收起/展开、翻页、导航圆点与常驻组件都直接到位，不再播放弹簧动画。
- 预览区域用棋盘格与彩色渐变衬托透明效果，拖动/点击数值即可看到变化。

## 计时与防睡眠

「计时」页有两个模式，用左上角页签切换：

- **倒计时**：点 5／10／25／45 分预设，或直接在命令面板说「开始 5 分钟倒计时」。
  开始后收起岛仔，药丸里的时钟会变成剩余时间（青色）；结束时在岛上提醒。
- **秒表**：开始后点「计次」记录分段时间，右侧显示最近三次；重置清空。

计时在岛仔运行期间一直有效，收起、切页或处理其它提醒都不会中断。

「设置 → 常规 → 防睡眠」或命令面板搜索「防睡眠」可以阻止系统休眠与息屏；
关闭开关或退出岛仔后恢复系统原来的睡眠策略。

## 系统状态

「系统」页每秒采样一次，用四块卡片展示 CPU 使用率、物理内存、网络上下行与系统盘容量：
CPU 与网络带 48 秒迷你曲线，内存与磁盘用进度条表示；数字与曲线缓动跟随采样，
鼠标悬停可查看具体用量。网络只统计硬件网卡，环回与 Hyper-V／WSL／VPN 等虚拟网卡
不会重复计入。首次打开约 1 秒后方可看到完整数据。点击 CPU／内存卡片可打开任务管理器，
点击网络卡片打开网络设置，点击磁盘条打开「此电脑」。

系统页和其他页面一样，可以在「设置 → 页面管理」里隐藏或调整顺序。

## 更新、卸载与数据目录

双击新版 `Daozai-Setup-v版本号-x64.exe`，可通过路径输入框或「浏览…」选择安装文件夹，勾选「创建桌面快捷方式」和「开机自启」，再点击「一键安装」。首次安装默认创建桌面快捷方式、不开机自启；升级默认保留现有选择。安装位置默认为 `%LOCALAPPDATA%\Programs\Daozai`，可改为其他有写入权限的文件夹，用户数据仍保存在 `%APPDATA%\Daozai`。

升级安装保留数据。若提示岛仔正在运行，先从托盘退出，再点击重试。

在 Windows 已安装应用中卸载会移除程序和快捷方式，但保留数据。若要清除账号，先在岛仔设置中移除对应连接，避免只删配置文件而留下系统凭据。

## 常见问题

**窗口没有出现：** 检查托盘是否已有实例、是否在全屏应用中、设置是否启用了全屏隐藏。

**邮箱登录失败：** 确认填的是授权码／App 专用密码、IMAP 已启用、账号没有被管理员限制。

**日程连接成功但没有安排：** 手动同步所选月份，确认平台授权的日历包含该日程；出现错误时保留错误文字即可，不要提供密码。

**验证码没有马上出现：** 确认邮件是否已到达收件箱，而非垃圾箱；检查岛仔是否运行、连接是否正常。

**图标或布局异常：** 反馈 Windows 版本、屏幕缩放比例、显示器数量和截图。截图先遮挡账号、验证码及私人日程。
