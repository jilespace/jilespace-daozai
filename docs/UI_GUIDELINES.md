# 岛仔 UI / 交互规范

这份文档记录当前界面的设计 token 与交互规则。新增页面、面板或 HUD 时先对齐这里的约定，
再通过 `daozai-record --gallery` 与离屏预览图做视觉回归。

## 1. 颜色

| 用途 | Token | 值 |
| --- | --- | --- |
| 岛体底色 | `theme::CARD` | `#161618` |
| 主文字 | `theme::WHITE` | `#FFFFFF` |
| 次级文字 | `theme::GRAY` | `#B2B2BA` |
| 弱化文字 | `theme::DIM` | `#8E8E99` |
| 强调蓝 | `theme::BLUE` | `#3EACF8` |
| 成功/完成 | `theme::GREEN` | `#30D158` |
| 警示 | `theme::YELLOW` | `#FFC43D` |
| 危险/专注 | `theme::RED` | `#F23046` |
| 卡片/控件底 | `theme::BTN` / `theme::TRACK` | `#28282B` / `#242427` |

- 页面强调色按功能分配：音乐=红、专注=番茄红、饮水/网络=蓝、待办/计时/进程=绿、天气/系统=青。
- 正文对比度目标 ≥ 4.5:1；弱化文字只用于元信息，不承载唯一操作入口。
- 颜色不直接写死 RGB 时优先使用 `theme::*` 或 `paint::mix/alpha`，保证面板与岛体一致。

## 2. 字体与层级

| 层级 | 字号 | 字重 | 典型用途 |
| --- | --- | --- | --- |
| 页标题 | `size::TITLE` 14.5 | Bold | 页面标题 |
| 大数字 | `size::HERO` 29 | Bold | 25:00、31%、1/2 |
| 正文 | `size::BODY` 11.5 | Regular | 列表、按钮 |
| 说明 | `size::SMALL` 11 | Regular | 描述、状态 |
| 元信息 | `size::TINY`/9–9.5 | Regular | 时间、单位、坐标轴 |
| 微型 | 8–8.5 | Regular | 排行/密集列表（仅在空间确实不足时使用） |

- 中文标题与强调使用 Semibold/Bold；数字与英文使用 Segoe UI，中文回退微软雅黑 UI。
- 同一卡片内最多两级字号；密集列表允许 9/8.5 两级，但不要混用 8.4、8.6 等碎字号。
- 文本超宽一律 `fit`/truncate 并保留 tooltip，不允许裁切半个字。

## 3. 间距、圆角与布局

- 展开面板：宽 `PW=419`，内容区左右边距 44，底部圆点区域高约 8。
- 页面标题基线 y=25；顶部日期/时钟行 y≈11–25；正文从 y=32 开始。
- 卡片圆角：大卡 10，浮层 12–18，按钮/芯片 6–9。
- 4pt 网格：8/12/16 为主；按钮高度 24–30；图标热区 ≥24pt。
- 浮层窗口统一无边框 + 透明底 + 自绘圆角；位置靠近触发点，避免遮挡岛体与选区。
- 面板打开/关闭 130ms 淡入淡出；悬停 90–110ms；页切换弹簧滑入 + 淡入淡出。
- 关闭「岛体动效」或系统禁用动画时：页面切换、岛体系统 HUD、浮层入场淡入全部
  直接落到终态，不保留过渡帧。
- 尊重「减少动画」设置：`bar_layout::animations_enabled()` 为 false 时只保留透明度变化。

## 4. 状态与反馈

- 每个异步区域必须覆盖：加载中 / 成功 / 失败 / 空 / 无搜索结果。
- 加载中优先用骨架或脉冲提示，不用旋转大图；失败信息留在原区域，不把错误抛到岛体。
- 危险操作（清空、删除全部）二次确认；可撤销操作保留 6 秒撤销入口。
- 操作成功反馈优先就地（状态变化、按钮态），需要跨界面提示再用岛体 toast。
- 可点击的岛体卡片/整块区域必须有悬停反馈：手型光标 + 轻微描边/底纹；
  不要出现「可点击但无任何视觉变化」的区域。
- 快捷键操作统一走系统 HUD：
  - 音量：岛体顶部系统 HUD（可拖动音量条、点喇叭静音），与硬件音量键同一入口。
  - 亮度 / 媒体：屏幕底部居中 OSD，1.4/1.6 秒自动消失，不抢焦点。
- 所有 HUD 同一时间不重叠：底部 OSD 自下而上堆叠，岛体 HUD 位于顶部。

## 5. 响应式与 DPI

- 逻辑坐标与 DPI 解耦：尺寸用 pt，截图像素按 `pixels_per_point` 换算。
- 浮层窗口位置需夹在显示器工作区内；贴图恢复时按窗口中心选择显示器并夹取。
- 设置窗口按显示器尺寸收缩（最小 600×450，极窄屏保留 420 宽），侧栏内容可滚动；
  标注编辑器按可用画布压低预览比例并收缩窗口，避免超出屏幕。
- 文本宽度使用 `fit` 或 truncate；密集列表允许隐藏次要列，不挤压主标题。
- 浮层尺寸统一通过 `panel::fitted_window_ctx` 夹到显示器：剪贴板最小 420×360、
  命令面板 440×340、通知 340×300；窄屏时高度优先收缩，内部列表改为滚动。

## 6. 预览与回归

- 岛体页面：`cargo run --features record --bin daozai-record -- --gallery preview/gallery`。
- 面板：对应测试的环境变量（如 `DAOZAI_CLIPBOARD_PREVIEW_DIR`、`DAOZAI_THEME_PREVIEW_DIR`）。
- 新交互必须同时补：行为断言 + 至少一张离屏渲染图；视觉变更需人工核对间距、对比度与截断。
