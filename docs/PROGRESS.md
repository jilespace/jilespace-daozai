## 2026-11-10 · Phase M：截屏保存

**已完成改动**
- 新增 `src/screenshot.rs`：把 RGBA 图片编码为 PNG；生成 CF_DIBV5（BITMAPV5HEADER +
  自底向上 BGRA，含 alpha mask）与 CF_DIB（32 位 BI_RGB）两种剪贴板数据；
  写入时同时提供注册格式 PNG，兼容聊天工具、画图与浏览器；保存到
  「图片\岛仔截图\岛仔截图-时间戳.png」（取不到系统图片目录时回退数据目录）。
- 框选遮罩新增用途参数：`Purpose::Ocr`（识别文字）与 `Purpose::Screenshot`
  （复制并保存）；提示文案、选区像素尺寸、Esc 取消与压暗样式保持一致。

  托盘菜单新增「截屏保存」、命令面板新增「截屏保存…」；截屏完成后岛上提示保存路径。

**新增功能（用户可见）**

## 2026-11-10 · Phase L：链接清理与通知免打扰

  去掉 `utm_*`、`share_*`、`fbclid`、`gclid`、`msclkid`、`spm`、`scm`、`si`、

  历史，但不亮铃铛、不弹岛上镜像横幅；设置 → 通知新增免打扰卡片。
- 补充 UI 与纯函数测试。

## 2026-11-10 · Phase K：真实音频频谱

**已完成改动**
- 新增 `src/audio.rs`：WASAPI 回环抓取默认输出设备混音（共享模式 + LOOPBACK），
  PCM 下混、1024 点汉宁窗 FFT、12 段对数频段（40 Hz–12 kHz）与响度归一化；
  后台线程约 30 Hz 推送频谱，失败时回退提示，关闭设置后线程立即退出。
- 绘制：新增 `paint::spectrum`（12 根底对齐能量条），替换收起药丸与歌词条上的
  装饰性播放条——音乐播放且可视化开启时显示真实频谱，否则保持原样。
- 设置：音乐与歌词页新增「真实频谱」开关（默认关闭）、说明与隐私提示；
  Shell 按设置启停服务，频谱 90 ms 无更新时自动回落，避免暂停后残留峰值。
- 录制器新增音频频谱演示场景。

**新增功能（用户可见）**
- 可选的系统音频真实频谱，显示在岛体播放位置；默认关闭、不保存音频。

- 实测回环冒烟（`DAOZAI_AUDIO_TESTS=1`，播放 Windows 提示音）成功捕捉到非零频谱。
- 纯逻辑测试覆盖 16/32 位下混、1.5 kHz 正弦峰值落点、静音平坦与绘制条数/范围。
- 截图核对收起药丸上的频谱条；未验证多声道环绕、独占模式与蓝牙设备切换。

**后续计划**

## 2026-11-10 · Phase D：剪贴板图片取字（OCR）

**已完成改动**
- 新增 `src/ocr.rs`：纯函数解析 Windows `CF_DIB`（1/4/8/24/32 位，调色板、
  自顶向下/自底向上、BI_RGB/BI_BITFIELDS）并兼容 DIBV5 与注册格式 PNG，带尺寸与数据完整性保护；
  `clean_text` 统一换行、去行尾空白、压缩空行。
- WinRT 识别：`SoftwareBitmap::CreateCopyFromBuffer` + `OcrEngine::TryCreateFromUserProfileLanguages`
  + `RecognizeAsync().get()`，全程本地、不上传；OCR 语言包缺失时给出可读提示。
- 入口：新增全局热键 `Ctrl+Alt+O`、托盘「识别图片文字」、剪贴板面板右上角菜单、
  命令面板（搜索「识别 / OCR / 图片」）。识别结果自动复制并插入剪贴板历史
  （新增 `clipboard::Service::insert`，不经过系统剪贴板）。
- 外壳：OCR 在后台线程执行，主线程 `poll_ocr` 收结果，不阻塞岛体动画；
  识别中/失败/成功都有岛上提示；`设置 → 常规 → 全局快捷键` 增加第三行说明。

**新增功能（用户可见）**
- 复制一张截图后按 `Ctrl+Alt+O`，几秒内得到可粘贴的文字，并自动进入剪贴板历史。

**验证**
- `cargo test --locked --features record -- --test-threads=1`：487 通过 / 37 忽略（含 8 个 OCR 单测）。
- DIB 解析用合成数据覆盖 24 位自底向上、32 位自顶向下、8 位调色板与损坏/超大图片。
- 端到端：用 egui 渲染 “HELLO 12345” 到 RGBA，经本机 Windows OCR 识别并断言含数字，
  说明 WinRT 识别链路真实可用（无语言包时自动跳过并打印提示）。
- 限制：本轮未在实机用真实截图与多显示器 DPI 场景验收；未支持 PNG/JPEG 剪贴板
  私有格式与区域截屏，后续补。

**后续计划**
- 区域截屏取字（框选屏幕区域 → OCR）。
- 识别结果预览面板与「重新识别 / 仅复制」选择。
- Phase E：小工具集（防睡眠、世界时钟、倒计时/秒表）。
