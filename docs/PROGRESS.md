## 2026-11-10 · Phase D：剪贴板图片取字（OCR）

**已完成改动**
- 新增 `src/ocr.rs`：纯函数解析 Windows `CF_DIB`（1/4/8/24/32 位，调色板、
  自顶向下/自底向上、BI_RGB/BI_BITFIELDS）并兼容 DIBV5 与注册格式 PNG，带尺寸与数据完整性保护；
  `clean_text` 统一换行、去行尾空白、压缩空行。
- WinRT 识别：`SoftwareBitmap::CreateCopyFromBuffer` + `OcrEngine::TryCreateFromUserProfileLanguages`
  + `RecognizeAsync().get()`，全程本地、不上传；OCR 语言包缺失时给出可读提示。
- 入口：新增全局热键 `Ctrl+Alt+O`、托盘「识别图片文字」、剪贴板面板右上角菜单、
  命令面板（搜索「识别 / OCR / 图片」）。识别结果自动复制并插入剪贴板历史
  （新增 `clipboard::Service::insert`，不经过系统剪贴板）。
- 外壳：OCR 在后台线程执行，主线程 `poll_ocr` 收结果，不阻塞岛体动画；
  识别中/失败/成功都有岛上提示；`设置 → 常规 → 全局快捷键` 增加第三行说明。

**新增功能（用户可见）**
- 复制一张截图后按 `Ctrl+Alt+O`，几秒内得到可粘贴的文字，并自动进入剪贴板历史。

**验证**
- `cargo test --locked --features record -- --test-threads=1`：487 通过 / 37 忽略（含 8 个 OCR 单测）。
- DIB 解析用合成数据覆盖 24 位自底向上、32 位自顶向下、8 位调色板与损坏/超大图片。
- 端到端：用 egui 渲染 “HELLO 12345” 到 RGBA，经本机 Windows OCR 识别并断言含数字，
  说明 WinRT 识别链路真实可用（无语言包时自动跳过并打印提示）。
- 限制：本轮未在实机用真实截图与多显示器 DPI 场景验收；未支持 PNG/JPEG 剪贴板
  私有格式与区域截屏，后续补。

**后续计划**
- 区域截屏取字（框选屏幕区域 → OCR）。
- 识别结果预览面板与「重新识别 / 仅复制」选择。
- Phase E：小工具集（防睡眠、世界时钟、倒计时/秒表）。

## 2026-11-10 · Phase C：系统状态页

**已完成改动**
- 新增 `src/perf.rs`：CPU（GetSystemTimes 差值）、物理内存（GlobalMemoryStatusEx）、
  网络上下行（GetIfTable2，仅统计硬件网卡、排除环回/虚拟网卡）、系统盘（GetDiskFreeSpaceExW）
  每秒采样；纯函数负责百分比、容量与速率格式化，另有真实计数器冒烟测试。
- 页面从 8 个扩到 9 个：`visible_pages`/`page_order` 改为 9 项并支持旧版 8 项顺序
  自动迁移（系统页接在最后）；页面管理、导航圆点、命令面板、设置说明同步更新。
- 新增系统页 UI：CPU（大号百分比 + 折线）、内存（用量条）、网络（上下行双曲线）、
  磁盘（容量条）四块卡片；每秒补历史点，曲线随时间轻微左移，数字与进度条弹簧缓动，
  卡片悬停显示具体读数和操作提示；点击 CPU/内存卡片打开任务管理器、网络卡片打开\n  网络设置、磁盘卡片打开「此电脑」。无数据时显示占位与「首次采样约 1 秒」。
- 页面打开时保持 30 帧刷新，收起后回到低功耗节奏；引擎新增 `paint::area`
  三角带填充，避免非凸折线区域被 `convex_polygon` 填错。
- 录制器 `--gallery` 增加系统页场景与合成曲线数据，便于逐张目检。

**新增功能（用户可见）**
- 岛内新增「系统」页：抬眼即可看到 CPU、内存、网络与磁盘的实时状态和最近 48 秒趋势，
  可在设置里显隐或调整顺序。

**验证**
- `cargo test --locked --all-targets --features record -- --test-threads=1`：476 通过、37 忽略。
- 真实 Windows 计数器冒烟测试通过（内存、磁盘、CPU 差值、网络速率均能读取）。
- `daozai-record --gallery` 输出 19 张页面截图，系统页深色截图逐项核对。
- 限制：本轮未在实机上长时间观察采样波动与多网卡切换；下次真机验收补上。

**后续计划**
- 系统页增强：GPU/温度（若可读）、进程占用排行、点击卡片打开任务管理器。
- Phase D：剪贴板 OCR 取字（Windows.Media.Ocr，本地识别）。

## 2026-11-10 · Phase B：命令面板

**已完成改动**
- 新增 `src/command_palette.rs`：`Ctrl+Alt+K` 呼出的命令面板。搜索框自动聚焦，
  `↑/↓` 选择、`Enter` 执行、`Esc` 关闭；查询为空时按「操作 / 页面 / 设置」分组，
  输入后跨组按标题、说明与关键词排序；应用名支持前缀、子串与子序列匹配。
- 数据能力：扫描开始菜单（`.lnk` / `.url`，跳过卸载、帮助类条目并按名称去重），
  启动应用；递归下降算式解析（`+ - * / % ^`、括号、负号，标准优先级）；
  单位换算（长度/重量/数据/速度/时间/温度，支持中英文单位与 `to` / `in` / `->`）。
- 新增 `src/panel.rs`：把石墨浮层、轻描边、阴影、键帽、图标按钮、空状态配色等
  视觉令牌抽成共享模块，剪贴板与命令面板共用，避免两套面板外观漂移。
- 全局热键：`native.rs` 支持第二个热键（`Ctrl+Alt+K`），与 `Ctrl+Alt+V` 同样
  注册 `WM_HOTKEY`；被占用时面板内提示，仍可从托盘菜单打开。
- 托盘菜单新增「命令面板」；`设置 → 常规` 新增「全局快捷键」卡片，集中展示两个热键。
- 修复搜索框 `desired_width` 占满整行导致清除按钮把浮层撑宽的问题（剪贴板同样修正）。
- 新增 11 个命令面板测试（匹配排序、选择边界、算式、换算、应用扫描、离屏渲染）
  和 6 张离屏 PNG（深/浅/计算/空结果/应用/换算）。

**新增功能（用户可见）**
- 一个键盘优先的入口：跳页面、跳设置、启动应用、做算术、换单位，`Enter` 即执行或复制。

**验证**
- `cargo test --locked --all-targets --features record -- --test-threads=1`：470 通过、37 忽略。
- `cargo build --locked --release --bin daozai`：通过。
- 离屏截图：`DAOZAI_CLIPBOARD_PREVIEW_DIR` / `DAOZAI_COMMAND_PREVIEW_DIR` 输出深色、浅色、
  计算、空结果等 PNG 并逐张检查对齐与截断（`preview/` 不入库）。
- 限制：本轮未在桌面实机按热键、启动真实应用或等待托盘菜单截图；下一次真机验收补上。

**后续计划**
- 命令面板继续增强：搜索剪贴板记录、翻译与快捷搜索、自定义常用命令与排序。
- Phase C：系统页（CPU/内存/网络/磁盘实时读数与迷你折线）。

## 2026-11-10 · Phase A：剪贴板快捷面板重设计收口

**已完成改动**
- 重写 `src/clipboard_ui.rs`：面板内容拆成独立的 `panel_ui`，不再与窗口创建耦合，
  这样测试与录制器可以在无窗口环境下渲染同一份界面。
- 视觉：石墨浮层 + 18px 圆角 + 柔和阴影 + 轻描边；标题栏键帽、搜索框聚焦描边、
  页签下划线、分组标签、行选中态（蓝色侧条 + 淡蓝底 + 细描边）、置顶黄色胶囊、
  固定底栏（目标应用 + 粘贴/仅复制 + 快捷键提示）。
- 交互：`↑/↓` 选择并滚动到可见位置；`Enter` 粘贴、`Ctrl+Enter` 仅复制、`Esc` 关闭
  （预览态先退回列表）；`Del` 删除；`空格` 非输入态切换预览；右键条目菜单
  （粘贴/仅复制/预览/置顶/删除）；搜索框失焦时直接打字会自动重新聚焦搜索。
- 新增状态：页签筛选（最近/置顶）、搜索命中行内高亮、多行/代码/链接类型图标与元信息、
  删除后 6 秒内可撤销、搜索无结果/置顶为空/历史为空/未开启四种空状态、
  面板内错误条（写入剪贴板失败保留面板并提示）、清空全部二次确认、
  面板菜单（暂停/恢复记录、清空、打开设置、关闭）。
- 主题：面板跟随系统深浅色，不再固定深色；滚动条使用低对比度滑轨与滑块。
- 粘贴流程：保留「先确认系统剪贴板写入成功，再关闭面板、恢复目标窗口、模拟 Ctrl+V」，
  失败时不清空面板并给出可读错误。
- 工程：新增 8 个面板行为测试与 2 个离屏渲染测试，导出深/浅/预览/未开启四张 PNG
  （`DAOZAI_CLIPBOARD_PREVIEW_DIR`）。

**新增功能（用户可见）**
- 剪贴板面板可以预览长文本、按「置顶」筛选、删除后撤销、跟随系统主题、
  在面板内看到失败原因；快捷键与鼠标操作都有明确回执。

**后续计划**
- Phase B：`Ctrl+K` 命令面板（功能页/设置/应用/换算），复用本轮的面板视觉令牌与渲染测试方式。
- 剪贴板追加：纯文本粘贴、复制链接时清理跟踪参数、图片 OCR 取字。
- 按 `docs/ROADMAP.md` 推进系统页、外观自定义与性能收口。
